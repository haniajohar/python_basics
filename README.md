# Notebook Exercises

This workspace contains a Python Jupyter notebook with beginner programming practice, including:

- conditionals and user input
- loops and simple calculations
- classes and inheritance
- a small menu-driven unit converter

## Files

- `Untitled0.ipynb` - the main notebook

## Usage

Open the notebook in VS Code or Jupyter and run the cells interactively.

## Git Ignore

This project includes a `.gitignore` that excludes common notebook and Python cache files.
